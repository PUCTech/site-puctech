## Descrição

O CareOn ajuda a organizar a saúde no dia a dia. No app é possível cadastrar remédios, cadastrar compromissos de saúde (como exames e cirurgias), marcar os remédios já tomados e pesquisar o preço de remédios na Drogasil.

Os preços vêm do site da farmácia e podem variar. Projeto desenvolvido em equipe, com foco no aprendizado prático.

## Objetivo e escopo

Construir uma aplicação funcional de gestão de saúde rotineira, com app mobile em React Native, API REST em Django, banco de dados PostgreSQL no Supabase e web scraping para a consulta de preços.

## Resultados e aprendizados

Aplicativo Android com build gerado pelo Expo.

Aprendizados: composição e organização de telas, integração do front-end com a API, autenticação por token e validação de dados, desenvolvimento de APIs REST, web scraping, uso do Supabase e deploy do back-end.
