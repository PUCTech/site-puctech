## Descripción

CareOn es una aplicación para organizar la salud en el día a día. Permite registrar medicamentos y citas médicas, como exámenes y cirugías, marcar los medicamentos ya tomados y consultar el precio de medicamentos en Drogasil.

Los precios vienen del sitio web de la farmacia y pueden variar.

## Objetivo y alcance

Construir una aplicación funcional para la gestión de la salud cotidiana, con una app móvil en React Native y Expo, una API en Django, una base de datos PostgreSQL en Supabase y web scraping para consultar los precios.

## Resultados y aprendizajes

El resultado es una aplicación para Android, generada con Expo.

Pedro Bizzari lideró el equipo y desarrolló la app móvil, además de integrar el front-end con la API. Liam Vedovato Lopes desarrolló el back-end en Django. João Victor Pereira Bicalho se encargó de la base de datos en Supabase y del web scraping.

En el front-end, el grupo practicó la organización de pantallas, la autenticación por token y la validación de datos. En el back-end, APIs REST, web scraping y despliegue.
