## Description

CareOn is an app for keeping your health organized day to day. You can register medicines and health appointments, such as tests and surgeries, mark the medicines you've already taken and look up medicine prices at Drogasil.

Prices come from the pharmacy's website and may vary.

## Goal and scope

To build a working app for managing everyday health, with a mobile app in React Native and Expo, an API in Django, a PostgreSQL database on Supabase and web scraping to look up prices.

## Results and lessons learned

The result is an Android app, built with Expo.

Pedro Bizzari led the team and built the mobile app, as well as integrating the front end with the API. Liam Vedovato Lopes developed the Django back end. João Victor Pereira Bicalho took care of the Supabase database and the web scraping.

On the front end, the group practiced screen organization, token authentication and data validation. On the back end, REST APIs, web scraping and deployment.
